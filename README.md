# Bản đồ số Thư Lâm 100

Website trực quan hóa kết quả **Chiến dịch 100 ngày vì Thư Lâm phát triển, vì hạnh phúc Nhân dân**.

## Nội dung
- Theo dõi các phần việc của 34 thôn.
- Dashboard tiến độ và nhóm nhiệm vụ.
- Ảnh minh chứng, ảnh trước – sau và mô hình tiêu biểu.
- Tra cứu theo thôn, lĩnh vực và trạng thái thực hiện.

Trang chính: `index.html`.

## Bản đồ
Website sử dụng **OpenStreetMap + Leaflet**, không cần Google Maps API key. Hỗ trợ lớp nền OpenStreetMap và lớp vệ tinh Esri; các công trình sẽ được ghim chính xác khi nguồn dữ liệu có Latitude/Longitude.

> Dữ liệu phục vụ công tác theo dõi, chỉ đạo và tuyên truyền của xã Thư Lâm.
